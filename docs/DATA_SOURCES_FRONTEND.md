# Источники данных FrameScope

> Историческое исследование перед Backend v0.1. Актуальные подключённые источники и лицензии — в [DATA_SOURCES.md](../DATA_SOURCES.md).

Проверено 31 октября 2026 года. Сейчас сайт не обращается к внешним API и не содержит результатов бенчмарков. Ниже — исследование вариантов, а не обещание подключённых сервисов. Условия необходимо повторно проверить перед интеграцией.

## RAWG — метаданные игр

- **Данные:** названия, описания, жанры, платформы, даты, изображения и ссылки на магазины. Это каталог, а не источник FPS для конкретного компьютера.
- **API:** REST API, нужен ключ. Примеры: `/api/games`, `/api/games/{id}`.
- **Условия:** требуется атрибуция RAWG и активная ссылка на каждой странице, использующей его данные. Перепродажа/перераспространение базы ограничены. Free-план описывает 20 000 запросов в месяц и ограничения размера коммерческого проекта; конкретные квоты сверять в кабинете.
- **Ограничения:** RAWG не заявляет владение всеми сторонними изображениями. Наличие файла в API не заменяет проверку прав; требования к ПК могут отсутствовать или иметь свободный текст. Ключ хранить на будущем сервере в переменных окружения.
- **Для FrameScope:** возможный источник каталога после проверки условий. Сейчас не подключён.
- **Ссылки:** [документация](https://rawg.io/apidocs), [условия](https://rawg.io/tos_api). На странице условий указана старая дата редакции — перед подключением проверить актуальность тарифа.

## CapFrameX — собственные игровые замеры

- **Данные:** времена кадров, FPS, статистика и данные сенсоров при соответствующей записи.
- **Доступ:** приложение и исходный код; README описывает записи JSON и дополнительный CSV. Это инструмент сбора, а не готовая открытая таблица FPS для всех игр и комплектующих.
- **Лицензия:** текущий основной LICENSE содержит MIT и уведомления о сторонних компонентах. При использовании кода проверять весь файл и зависимости. Лицензия программы не даёт автоматических прав на чужие записи и скриншоты.
- **Ограничения:** нужны собственные тесты или явное разрешение автора результатов. Фиксировать условия каждого запуска и метод расчёта метрик; различать реально отрисованные и сгенерированные кадры.
- **Для FrameScope:** подходящий кандидат для ручного сбора первых замеров и последующего импорта. Импорт сейчас не реализован.
- **Ссылки:** [репозиторий и README](https://github.com/CXWorld/CapFrameX), [лицензия](https://github.com/CXWorld/CapFrameX/blob/master/LICENSE), [официальный сайт](https://www.capframex.com/).

## Intel PresentMon — первичные данные о кадрах

- **Данные:** захват характеристик графических приложений Windows и времена кадров; консольный инструмент умеет выводить CSV.
- **Доступ:** открытый код, консольное приложение, SDK/служба. Это локальный инструмент, не веб-API с готовыми игровыми результатами.
- **Лицензия:** MIT для основного проекта; при распространении учитывать сторонние компоненты и соответствующие уведомления.
- **Ограничения:** сайт сам не может запускать захват Windows. Требуется локальный инструмент, а для сравнения — одинаковые сцены, настройки и описанная методика. Не путать лицензию кода и права на сторонние результаты.
- **Для FrameScope:** возможная основа будущего Companion или собственных тестов, не нужен для текущего frontend.
- **Ссылки:** [репозиторий](https://github.com/GameTechDev/PresentMon), [консольное приложение и CSV](https://github.com/GameTechDev/PresentMon/blob/main/README-ConsoleApplication.md), [лицензия](https://github.com/GameTechDev/PresentMon/blob/main/LICENSE.txt).

## Phoronix Test Suite / OpenBenchmarking.org

- **Данные:** системные тесты, профили и результаты с описанием окружения; покрытие зависит от конкретного теста. Не универсальный каталог Windows FPS.
- **Доступ:** PTS поддерживает локальные XML-результаты и публикацию на OpenBenchmarking.org. Возможности централизованного API и права массового экспорта в ходе проверки не подтверждены: OpenBenchmarking.org вернул 403.
- **Лицензия:** PTS — GNU GPL; лицензию инструмента нельзя переносить на все опубликованные результаты. Право повторного использования базы OpenBenchmarking.org не установлено.
- **Ограничения:** существенная доля тестов ориентирована на Linux; сравнивать разные ОС, драйверы и версии без учёта условий нельзя. До выяснения прав автоматический сбор не подключать.
- **Для FrameScope:** источник для изучения методики и структуры результатов. Для текущего проекта не импортируется.
- **Ссылки:** [официальные возможности PTS](https://www.phoronix-test-suite.com/?k=features), [документация](https://github.com/phoronix-test-suite/phoronix-test-suite/blob/master/documentation/phoronix-test-suite.md), [OpenBenchmarking.org](https://openbenchmarking.org/).

## Как выбирать данные для будущего прогноза

Для начала предпочтительны собственные повторяемые замеры или явно лицензированный набор. Обзорные графики без разрешения не копировать. Нужны: источник и разрешение, CPU/GPU и варианты моделей, память, ОС и драйвер, игра/издание/версия, сцена, разрешение, настройки, RT, апскейлинг, генерация кадров, длительность и число повторов. Метод 1% Low нужно зафиксировать отдельно: разные программы могут рассчитывать показатель по-разному.
