# FrameScope

> Архив описания статического frontend до Backend v0.1. Актуальные команды и пути — в [README](../README.md). Файлы интерфейса теперь находятся в public/, полный сайт запускается через Express, не Live Server.

Учебный frontend-прототип на HTML5, CSS3, Bootstrap 5.3.8 и обычном JavaScript (ES-модули). Интерфейс на русском. Сборка, React и серверное приложение не нужны.

## Как запустить через VS Code

1. Открой папку `project_gamestat` через **File → Open Folder**.
2. В разделе Extensions установи расширение **Live Server** от Ritwick Dey.
3. Нажми правой кнопкой на `index.html` → **Open with Live Server**.
4. Страница откроется по адресу вроде `http://127.0.0.1:5500/index.html`.
5. Для каталога воспользуйся меню сайта. Пример страницы игры: `game.html?id=control`.

Не открывай HTML двойным щелчком через `file://`: браузер ограничивает импорт JavaScript-модулей. Live Server раздаёт файлы по HTTP и обновляет страницу при сохранении. Если он выбирает другой порт, это нормально.

Bootstrap хранится в `assets/vendor/bootstrap/`, поэтому для работы сайта после скачивания проекта не требуется CDN или API-ключ. Официальные ссылки в блоках источников открываются в интернете.

## Что работает

- Общая адаптивная навигация, в том числе раскрывающееся мобильное меню.
- Bootstrap-карусель с тремя слайдами, индикаторами и стрелками; без автопереключения.
- Форма выбора CPU, GPU, RAM, игры, разрешения и качества, проверка обязательных полей.
- После отправки формы — сводка выбранных параметров и объяснение отсутствия FPS. Изменение полей сбрасывает старую сводку. Параметры не отправляются на сервер и не сохраняются между страницами.
- Главная с преимуществами и шестью играми.
- Каталог из десяти игр: поиск без учёта регистра, фильтр жанра, количество результатов, пустое состояние и сброс фильтров.
- Единая страница игры по параметру `id`. Для отсутствующего или неизвестного ID отображается понятное сообщение.
- Поддержка клавиатуры, видимый фокус, подписи полей, сообщения для скринридеров и `prefers-reduced-motion`.

## Как устроены файлы

```text
index.html                         Главная и карусель
catalog.html                       Поиск и сетка каталога
game.html                          Универсальный шаблон игры
assets/
  css/styles.css                   Палитра, оформление, адаптивность
  js/
    data/games.js                  Локальные метаданные десяти игр
    data/hardware.js               Варианты комплектующих и настроек
    services/catalog.js            Получение и фильтрация данных
    ui.js                          Общие меню, подвал, карточки
    forms.js                       Общая форма и её проверка
    home.js                        Подключение главной
    catalog.js                     Обработка поиска и фильтров
    game.js                        Выбор игры из URL и заполнение страницы
  images/                          Оригинальные SVG-иллюстрации и favicon
  vendor/bootstrap/                Bootstrap 5.3.8 и лицензия
tests/catalog.test.mjs             Проверки данных, поиска и маршрутов
DESIGN.md                          Визуальные правила
AGENTS.md                          Правила работы с проектом
DATA_SOURCES.md                     Исследование источников и ограничения
```

**HTML** — структура страницы: секции, заголовки, место для формы. **CSS** — внешний вид и перестроение страницы при изменении ширины окна. **Bootstrap** — готовая сетка и поведение меню/карусели; наши стили подключаются после него.

**JavaScript-модуль** — отдельный файл, который экспортирует функции или данные и импортирует нужное из других файлов. Например, `catalog.js` получает значение поиска, вызывает `filterGames()` из `services/catalog.js` и передаёт результат общей функции карточек из `ui.js`.

Метаданные не смешаны с HTML. Сейчас сервис читает локальный массив. В будущем здесь можно добавить `fetch()` — запрос к нашему серверу; тогда также понадобится асинхронная загрузка и обработка сетевых ошибок в страницах. Это граница для развития, а не готовый backend.

В `game.html?id=control` часть после `?` — параметры URL. `game.js` читает `id`, ищет запись в каталоге и заполняет тот же шаблон. Поэтому десять отдельных страниц не требуются.

## Как безопасно изменять

- Цвета меняй в CSS-переменных в начале `styles.css`.
- Новую игру добавляй в `data/games.js`: уникальный ID, название, жанр, авторское описание, проверенный источник и локальное изображение. Поле `released` необязательное; дата должна иметь формат `YYYY-MM-DD`.
- Модели CPU/GPU добавляй в `data/hardware.js`. Перечень не задаёт их скорость.
- Общее меню редактируй в `ui.js`.
- Учитывай `DESIGN.md` и проверяй ширины 320, 375, 768, 1024 и 1440 px.

## Проверки

Если установлен Node.js 18 или новее, запусти из папки проекта:

```text
node --test tests/catalog.test.mjs
```

Команда использует встроенный тестовый инструмент Node; установка npm-пакетов для этих проверок не нужна. Файл `package.json` только включает ES-модули и даёт сокращение `npm test`; сборки сайта нет. В PowerShell при запрете запуска npm.ps1 можно использовать `npm.cmd test`, не меняя системную политику.

Ручная проверка: переключи все слайды, открой мобильное меню, отправь пустую и заполненную формы, поищи Control и неизвестное название, выбери жанр, открой карточку и затем `game.html?id=unknown`. Пройди кнопки клавишей Tab. Браузерная проверка и её результаты фиксируются в отчёте по выполненной работе.

## Ограничения первой версии

Нет базы бенчмарков, прогноза FPS, реальных графиков, сравнения конфигураций, аккаунтов, сообщества, автоопределения железа и Windows Companion. Эти возможности не реализованы. Прочерки в показателях означают отсутствие данных, а не нулевую производительность. Пресеты графики пока общие: параметры конкретной игры, RT, апскейлинг и генерацию кадров нужно будет описать перед расчётами.

Изображения созданы для проекта в SVG и являются временными оригинальными иллюстрациями. Это не скриншоты и не официальные обложки игр. Даты без однозначного источника не заполнены; готовых системных требований пока нет. Никакие внешние игровые API не подключены, секретных ключей нет.

## Результат проверки первой версии

Проверено 31 октября 2026 года: 6 автоматических тестов Node.js прошли. В установленном Chrome без видимого окна проверены форма и её сброс, поиск, фильтры, все десять игр, неизвестные ID, стрелки и индикаторы карусели, мобильное меню и reduced motion. Горизонтальной прокрутки нет: главная проверена при 320, 375, 768, 1024, 1440 и 1920 px; каталог и страница игры — при 320, 375, 768, 1024 и 1440 px. Ошибок JavaScript и загрузки ресурсов не обнаружено. Скриншоты главной при 375 и 1440 px просмотрены визуально. Проверка выполнена временным сценарием вне исходников; воспроизводимые тесты данных находятся в tests/catalog.test.mjs. Другие браузеры и реальный сенсорный экран пока не проверены.
